# 🚀 IMSP - School Management Portal

*(Inspired by Indian Military School, Pulgaon)*

🔗 **Live Demo:**
https://chetandhapkas.github.io/IMSP-Frontend/

---

## 📌 Overview

IMSP (School Management Portal) is a **frontend web application** developed using React.
It provides a simple and structured interface for managing student-related information and basic administrative workflows.

This project focuses on **frontend development, UI design, and user interaction handling**.

---

## ✨ Features

* 📝 Student Registration Form
* 🔐 Admin Login Interface (UI only)
* 📊 Dashboard Layout
* 📄 Data Display on Screen
* 🧾 PDF Generation using jsPDF
* 📱 Responsive Design (Mobile + Desktop)

---

## 🛠️ Tech Stack

* ⚛️ React.js
* 💻 JavaScript (ES6)
* 🎨 HTML5
* 🎯 CSS3
* 📄 jsPDF

## ▶️ Run Locally

1. Clone the repository

git clone https://github.com/Chetandhapkas/IMSP-Frontend.git
```

2. Navigate to project folder


cd IMSP-Frontend
```

3. Install dependencies


npm install
```

4. Start the application


npm start
```

## ⚠️ Important Note

* This project currently includes **only frontend implementation**
* No backend, database, or API integration is implemented
* Admin login is **UI-based only (no real authentication system)**
